# Upazila Map of Jessore District

## Project Overview
This project was created using ArcMap. The map shows the upazilas of Jessore district with cartographic elements.

## Features
- Upazila boundary
- Legend
- Scale bar
- North arrow
- Index map
- Basemap

## Software Used
- ArcMap

## Output
JPEG map of Jessore district upazilas.
