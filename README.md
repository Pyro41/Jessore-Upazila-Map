# Jessore Upazila Map

This repository contains a digitized upazila map of Jessore District, Bangladesh, created using ArcMap. The project includes the exported map layout, the ArcMap project file, and a zipped shapefile containing the required shapefile components.

## Project Description

The main objective of this project is to digitize the upazilas of Jessore District and present them in a clear cartographic layout. The final map shows the upazila boundaries with labels, a legend, scale bar, north arrow, topographic basemap, and an index map of Bangladesh.

## Files Included

- `Jessore Dizitization.jpg` — exported JPEG map layout of Jessore District
- `Jessore Dizitization.mxd` — ArcMap project file
- `Upazilas_of_Jessore_Shapefile.zip` — zipped shapefile containing the necessary shapefile components
- `README.md` — project description and file information

## Shapefile Information

The zipped shapefile contains the main files required to open and use the GIS data:

- `.shp` — stores the geometry of the upazila polygons
- `.shx` — stores the shape index
- `.dbf` — stores the attribute table
- `.prj` — stores the projection/coordinate system information
- `.xml` — optional metadata file describing the shapefile

## Software Used

This map was created using:

- ArcMap
- Topographic basemap
- Digitized polygon shapefile of Jessore upazilas

## How to Use

To use the shapefile, download `Upazilas_of_Jessore_Shapefile.zip`, extract the files, and open the `.shp` file in ArcMap, ArcGIS Pro, or QGIS.

To view the final map layout, open the exported JPEG file included in this repository.

## Map Elements

The exported map includes:

- Title
- Upazila boundaries
- Upazila labels
- Legend
- Scale bar
- North arrow
- Topographic basemap
- Index map

## Purpose

This repository was prepared as part of a GIS digitization and mapping exercise. It demonstrates the process of creating a district-level upazila map using digitized spatial data and standard cartographic elements.
